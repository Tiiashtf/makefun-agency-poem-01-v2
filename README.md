# Agency Poem — Round 2: "The Hinge"

An original poem about agency — the hinge between wanting and doing — with a
deterministic program that writes it to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
exactly the same bytes on every run. Python 3 standard library only — no
network, no randomness, no wall clock.

## The poem

"The Hinge" — about the smallest part of the door being the only part that
decides, and how the hinge is oiled by use: each time you choose, choosing
gets easier.
